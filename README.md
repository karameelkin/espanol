# Español — 1000 слов

Минималистичное PWA-приложение для изучения 1000 самых частых испанских слов
(кастильское произношение) с интервальными повторениями и аудио.

## Что внутри

- **FSRS-6** — тот же алгоритм повторений, что сейчас по умолчанию в Anki
  (интервалы новых карточек: Забыл → в сессии, Трудно → 1д, Норм → 2д, Легко → 8д).
- **Аудио без обрезки** — нативный плеер ждёт конца клипа, слово и фраза
  озвучиваются отдельно, следующая карточка предзагружается.
- **Офлайн** — service worker кеширует оболочку и аудио; кнопка
  «Скачать всё для офлайна» (~32 МБ) подтягивает все клипы разом.
- **Прогресс** хранится на устройстве (IndexedDB), сервер не нужен.

## Установка на iPhone

1. Открой ссылку сайта в **Safari** (именно Safari, не Chrome).
2. Нажми кнопку «Поделиться» → **«На экран „Домой“»**.
3. Иконка (испанский флаг) появится на домашнем экране — запускается как обычное приложение, на весь экран.
4. Один раз внутри нажми «Скачать всё для офлайна» — дальше работает без интернета.

## Локальный запуск (для разработки)

```bash
cd spanish
python3 -m http.server 8123
# открой http://127.0.0.1:8123/
```

## Тесты

```bash
node tests/fsrs.test.mjs
```

## Структура

- `deck.json` — 1000 карточек (слово, перевод, фраза, перевод фразы, имена аудиофайлов).
- `audio/` — 2000 mp3 (слово + фраза на карточку).
- `fsrs.js` — планировщик FSRS-6 (переиспользуется в браузере и в тестах).
- `app.js` — логика сессии и UI. `db.js` — IndexedDB. `audio.js` — плеер.
- `sw.js` — service worker (офлайн). `manifest.webmanifest`, `icons/` — PWA.

Колода сконвертирована из Anki-файла `spanish-1k-core-castellano-recast.apkg`
(картинки намеренно исключены).
